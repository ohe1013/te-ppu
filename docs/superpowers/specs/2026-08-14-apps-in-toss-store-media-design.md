# 앱인토스 제출 이미지 세트 설계

## 목적

앱인토스의 `테뿌리스` 앱 정보에 사용할 로고, 대표 썸네일, 세로 스크린샷을 현재 게임 캐릭터와 실제 플레이 화면에 맞춰 제작한다. 제출용 이미지만 추가하며 게임 규칙과 UI 동작은 변경하지 않는다.

| `app-logo-teppu.png` | 600×600 PNG | 리벳, 코일, 빛나는 낙하 블록, 기어라이트 타워 |
| `thumbnail-teppu.png` | 1932×828 PNG | 리벳과 코일을 중심으로 타워와 블록 대전 분위기를 보여주는 가로 대표 이미지 |

최종 파일은 `artifacts/apps-in-toss/store-media/`에 저장한다. 기존 `public/assets/brand/app-logo.png`는 검토가 끝날 때까지 덮어쓰지 않는다.

## 로고

현재 로고의 노을 하늘, 기어라이트 타워, 빛나는 노란 낙하 블록, 역동적인 위쪽 팔 동작과 정사각형 구도를 유지한다. 기존 인물과 금속 올빼미만 프로젝트 캐릭터로 교체한다.

- 리벳은 `public/assets/characters/hero-engineer/full.webp`를 외형 기준으로 사용한다.
- 파란 머리, 은색 고글, 빨간 목도리, 크림색 작업복, 노란 장갑, 빨강·청록 공구 가방을 유지한다.
- 리벳은 빛나는 노란 낙하 블록을 머리 위로 들어 올린다.
- 코일은 `public/assets/characters/owl-companion/full.webp`를 외형 기준으로 사용한다.
- 코일은 파랑·크림 깃털, 금색 고글, 빨간 망토와 톱니바퀴 받침이 보이도록 왼쪽 아래에 배치한다.
- 작은 앱 아이콘에서도 얼굴과 블록이 먼저 읽혀야 한다. 머리와 고글은 프레임에 닿거나 잘리지 않는다.
- 글자, 투명 배경, 둥근 모서리, 워터마크는 넣지 않는다.

## 대표 썸네일

로고의 캐릭터 정체성과 실제 게임의 대전 정체성을 함께 보여준다. 왼쪽에는 리벳과 코일, 오른쪽에는 타워와 두 개의 블록 보드가 읽히는 구도를 사용한다. 장식 문구는 넣지 않고 `테뿌리스` 로고가 준비된 경우에만 짧게 사용할 수 있다. 실제 게임에 없는 캐릭터, 아이템, 결제 요소는 추가하지 않는다.

## 스크린샷

스크린샷은 이미지 생성으로 재구성하지 않고 현재 앱을 실제로 실행해 캡처한다. 각 화면은 636×1048 뷰포트에서 캡처하며, 테스트용 안내·브라우저 장식·개발 도구는 포함하지 않는다.

1. 타이틀: `테뿌리스`의 시작 경험, 선택한 리벳, 점수와 주요 메뉴가 보인다.
2. 타워: 코일, 층별 라이벌, 현재 진행 층과 난이도 선택이 보인다.
3. 대전: 양쪽 보드, 리벳과 상대 캐릭터, 다음 블록과 터치 조작이 모두 보인다.

## 제작 및 검증

로고 편집과 대표 썸네일의 새 일러스트는 이미지 생성 편집을 사용하고, 리벳과 코일 원본을 각각 캐릭터 참조로 제공한다. 스크린샷은 Playwright로 실제 앱 상태를 만들고 캡처한다.

완료 전에 모든 PNG의 너비·높이, 색상 모드, 알파 사용 여부와 파일 손상 여부를 검사한다. 로고는 96×96 축소 미리보기에서도 리벳, 코일과 낙하 블록이 구분되어야 한다. 스크린샷은 잘린 얼굴, 버튼, 보드 또는 안전 영역이 없어야 한다.
