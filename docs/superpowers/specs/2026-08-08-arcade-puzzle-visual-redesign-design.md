# 아케이드 퍼즐 시각 개편 설계

## 목표

현재의 절차형 보라색 UI와 단순한 층 배경을 폐기하고, 90년대 아케이드 퍼즐 대전 게임의 화면 문법을 오리지널 에셋으로 재구성한다. 참고 방향은 다음과 같다.

- 탑 화면: 한 장의 수직 탑 지도, 다섯 개의 층 노드, 층별 라이벌 초상화, 구름·깃발·경로 연출
- 대전 화면: 양쪽 보드가 동등하게 보이는 아케이드 대전판, 캐릭터 얼굴판, 공격 화살표와 아이템 패널
- 결과/인트로: 큰 캐릭터 일러스트, 말풍선형 패널, 원색 테두리와 별·리본 장식
- 테트리스 블록: 기존 fallback 렌더링의 단순하고 선명한 색·윤곽을 유지하고, authored 타일은 fallback과 같은 모양으로 되돌린다

특정 게임의 캐릭터, 로고, 스프라이트, 문구, 고유 UI를 복제하지 않는다. 색 대비, 큰 초상화, 수직 진행 지도, 말풍선형 정보 패널처럼 장르의 일반적인 표현만 오리지널 디자인으로 사용한다.

## 에셋 패키지

`mode: assets`와 85개 canonical reference 구조는 유지한다.

- 7개 캐릭터 전신과 상태별 초상화: 동일한 밝은 셀·픽셀 혼합 스타일, 초록색 chroma-key 원본에서 투명 WebP로 변환
- 타워 및 5개 층 배경: 840×1480 수직 구성, 층별 팔레트와 목적지를 분명하게 구분
- 블록 7종/garbage: fallback의 기존 단순 블록 색과 내부 광택을 유지
- 아이템/전투 atlas/UI 아이콘: 두꺼운 어두운 윤곽, 별·구름·리본·번개 장식으로 재제작
- 오디오: 기존 cue/track contract를 유지하되 밝은 16-bit 아케이드 신스 톤으로 다시 생성

생성 스크립트는 재현 가능하게 유지하고, 선택적 MP3 인코더가 없는 환경에서도 구조 검사를 통과하는 fallback을 제공한다.

## UI 변경

- `TowerScreen`: 세로 지도 카드와 floor node를 사용한다. 잠긴 층은 자물쇠/구름으로 표현하고 숫자 목록은 사용하지 않는다.
- `FloorIntroScreen`/`ResultScreen`/`EndingScreen`: 배경·전신 아트·대화 패널을 겹쳐 사용하고, 큰 제목과 버튼은 아케이드 패널 스타일로 통일한다.
- `MatchScreen`: 보드 위 HUD를 밝은 캐릭터 플레이트와 아이콘 패널로 바꾼다. `PLAYER`/`RIVAL`을 고유 캐릭터 이름과 색상으로 표현한다.
- combo, incoming, 아이템 수량, freeze tick 등 내부 숫자는 화면에 직접 출력하지 않는다. 아이템은 활성/비활성 아이콘과 시각적 링으로 표시하고, 기존 `data-testid`는 숨김 상태로 유지해 기능 테스트와 접근성 회귀를 보호한다.
- 조이스틱·회전·행 선택·설정/종료 기능은 유지하되, 원형 장식과 노란색 선택 강조로 같은 시각 언어를 적용한다.

## 검증 기준

- `ASSETS_REQUIRED=1 npm run check:assets` 통과
- `npm run typecheck` 통과
- `npm run build:web` 및 Apps-in-Toss 패키지 검증 통과
- HUD 숫자가 시각적으로 노출되지 않고 아이템/보드/공격 피드백이 유지됨
- 360×640, 430×932 E2E에서 탑→인트로→대전→결과 흐름과 다섯 층 화면이 유지됨
